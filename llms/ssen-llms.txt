# Scottish and Southern Electricity Networks (SSEN)

> SSEN is the SSE plc electricity networks business in Great Britain — the poles-and-wires
> layer, not an energy retailer. SSEN Distribution is the licensed Distribution Network
> Operator for two GB licence areas (SHEPD in the north of Scotland, SEPD in central
> southern England) serving over 3.9 million homes and businesses; SSEN Transmission owns
> and operates the high-voltage transmission system for the north of Scotland. SSEN
> publishes four public APIs across two open data portals and two bespoke services. Grid
> and market data are genuinely open; there is no consumer data API, because Great Britain
> mandates smart-meter infrastructure and open-data disclosure rather than a consumer data
> right.

## What an agent needs to know first

- Four APIs, one OpenAPI. Only the SSEN Transmission Explore API has a machine-readable
  contract, and it is the Opendatasoft platform's spec, not SSEN-authored.
- Everything is read-only. There are no POST/PUT/PATCH/DELETE operations on any public
  SSEN surface, so there is no idempotency contract and no write risk.
- Three of four APIs need no credential. Only NeRDA is gated, by a free self-serve API key.
- `data-api.ssen.co.uk` returns HTTP 403 to a default curl User-Agent. Send a normal
  browser User-Agent. That is WAF bot filtering, not authentication.
- The Transmission Explore API allows roughly 100 anonymous calls per calendar day. Use
  the export endpoints instead of paging.
- No consumer, account, meter or premise entity exists anywhere in the public data model.

## APIs

- [SSEN Distribution Data Portal API](https://data.ssen.co.uk/): CKAN 2.10.10 Action API,
  45 open datasets, anonymous. Base URL `https://data-api.ssen.co.uk/api/3/action`.
  Substations, LV feeder smart meter half-hourly usage, Embedded Capacity Register,
  flexibility market registers, DFES, licence area boundaries, Long Term Development
  Statements. Mostly CC BY 4.0.
- [SSEN Power Track Real Time Outage API](https://data.ssen.co.uk/@ssen-distribution/realtime_outage_dataset):
  anonymous JSON, planned and unplanned outages with fault reference, type, lat/long,
  estimated restoration time and affected postcodes. Base URL
  `https://external.distribution.prd.ssen.co.uk/opendataportal-prd/v4/api`
  (`/getallfaults`, `/getbyid/{reference}`). CC BY 4.0.
- [SSEN NeRDA API](https://www.ssen.co.uk/our-services/tools-and-maps/near-real-time-data-access-nerda-portal/):
  near real-time power flow from EHV, HV and LV networks. Base URL
  `https://nerda.opengrid.com/api`. Requires a free SSEN account, acceptance of the
  portal terms, and an API key minted in the portal API console. Anonymous calls to the
  documented endpoints return 404.
- [SSEN Transmission Open Data Explore API](https://ssentransmission.opendatasoft.com/):
  Opendatasoft Explore API v2.1 over 60 CC BY 4.0 transmission datasets — ETYS circuits
  and fault levels, ground investigation points and related network records — via 16
  read-only GET operations for catalog search, dataset records, facets and exports
  (CSV, Parquet, GPX, DCAT). Base URL
  `https://ssentransmission.opendatasoft.com/api/explore/v2.1`.

## Regulatory context

- Ofgem **Data Best Practice** is a licence condition under RIIO-ED2: network licensees
  must treat data as **Presumed Open**, subject to **Open Data Triage**. SSEN attaches
  published Data Triage record PDFs to its datasets.
- GB smart meter traffic runs through the licensed **Smart DCC** monopoly under the Smart
  Energy Code. SSEN takes smart meter data through that route via its smart meter adapter.
- SSEN was the first GB DNO to publish full smart meter half-hourly consumption data,
  aggregated to no fewer than five properties per LV feeder.
- There is **no** GB equivalent of the Australian Consumer Data Right or Ontario's Green
  Button regulation for energy. No SSEN API exposes an individual customer's usage or
  billing data, and none is required to.
